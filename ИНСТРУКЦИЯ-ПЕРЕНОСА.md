# Инструкция по переносу и запуску сайта

## Что находится в архиве

В архиве лежит готовая папка сайта. В ней уже есть карта, стили, данные команд и все подключенные изображения.

Важные файлы и папки:

- `index.html` - главный файл сайта.
- `assets` - карта и изображения проектов.
- `data` - данные команд и координаты карты.
- `app.js` и `styles.css` - логика и внешний вид сайта.

Не переименовывайте файлы и папки внутри сайта, иначе часть изображений или точек может не открыться.

## Как перенести на другой компьютер

1. Скопируйте архив на флешку, в облако или отправьте его любым удобным способом.
2. На другом компьютере распакуйте архив в обычную папку.
3. Откройте распакованную папку.
4. Дважды нажмите на файл `index.html`.
5. Лучше открывать сайт в Chrome, Edge или Яндекс Браузере.

## Как запустить на интерактивной панели

1. Откройте `index.html` в браузере.
2. Включите полноэкранный режим клавишей `F11`.
3. Поставьте масштаб браузера `100%`.
4. Если панель 16:9, сайт должен занимать экран без прокрутки вверх-вниз.

## Если сайт не открылся двойным кликом

Иногда браузер на другом компьютере может ограничивать локальные файлы. Тогда сайт можно открыть через локальный адрес.

### Windows

1. Откройте распакованную папку сайта.
2. Нажмите в адресной строке проводника, введите `cmd` и нажмите Enter.
3. В открывшемся окне введите:

```bash
python -m http.server 8000
```

4. Откройте в браузере:

```text
http://localhost:8000
```

Чтобы остановить запуск, нажмите `Ctrl+C` в окне командной строки.

### macOS

1. Откройте Терминал.
2. Перейдите в распакованную папку сайта.
3. Введите:

```bash
python3 -m http.server 8000
```

4. Откройте в браузере:

```text
http://localhost:8000
```

Чтобы остановить запуск, нажмите `Ctrl+C`.

## Как обновлять фото позже

Когда будут готовы визуализации и фото команд-победителей, их нужно положить в папку `assets/projects` с теми именами, которые уже прописаны в данных сайта.

Миниатюры для команд 11-30 места лежат отдельно в папке `assets/top30` и называются `rank-11.png`, `rank-12.png` и так далее до `rank-30.png`. Сейчас там стоят фирменные заглушки; их можно заменить реальными изображениями с теми же именами.

После этого сайт можно снова упаковать в архив и перенести на панель.
