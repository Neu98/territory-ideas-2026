# Как перенести и запустить сайт

## Быстрый запуск

1. Распакуйте архив.
2. Откройте папку `altai-ideas-site`.
3. Дважды нажмите на файл `index.html`.
4. Откройте в Chrome, Edge или Яндекс Браузере.
5. Для интерактивной панели включите полноэкранный режим клавишей `F11` и поставьте масштаб `100%`.

## Важно

Не переименовывайте файлы и папки внутри сайта. Особенно важны папки `assets` и `data`: в них лежат карта, изображения и данные команд.

## Если двойной клик не сработал

Иногда браузер на другом компьютере ограничивает запуск локальных файлов. Тогда откройте сайт через локальный адрес.

### Windows

1. Откройте папку `altai-ideas-site`.
2. Нажмите в адресной строке проводника, введите `cmd` и нажмите Enter.
3. Введите:

```bash
python -m http.server 8000
```

4. Откройте в браузере:

```text
http://localhost:8000
```

Остановить запуск можно клавишами `Ctrl+C`.

### macOS

1. Откройте Терминал.
2. Перейдите в папку `altai-ideas-site`.
3. Введите:

```bash
python3 -m http.server 8000
```

4. Откройте в браузере:

```text
http://localhost:8000
```

Остановить запуск можно клавишами `Ctrl+C`.

## Как добавить изображения позже

Новые фото и визуализации победителей нужно класть в папку `assets/projects` с теми именами файлов, которые уже прописаны в данных сайта. Миниатюры для команд 11-30 места лежат в папке `assets/top30` и называются `rank-11.png`, `rank-12.png` и так далее до `rank-30.png`; сейчас там стоят фирменные заглушки. После добавления изображений сайт можно снова упаковать в архив.
